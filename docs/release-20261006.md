# 0.3.1 development snapshot — 20261006.1

One unified x86_64 ISO supersedes the separate desktop, security, Vector and
local-AI variants. The older x86 and ARM console prototypes remain historical
assets in release 0.3.0; no current desktop support is claimed for them.

The clean 32 GiB VMDK is built from the release filesystem, not exported from a
personal VM. Both images include the mouse-enabled kernel, Aether Glass and
icon motion. Personal VM updates are applied separately with a complete backup.

## Verification

- ISO: BIOS and UEFI boot, login and feature checks passed.
- Clean VMDK: image integrity check, BIOS and UEFI boot, login and feature checks passed.
- Each boot check reported zero failed system services and active LightDM/local AI.
- Sound theme: eight regression tests passed, including system-wide lookup and user precedence.
- Icon motion: rendering tests passed at 1x/2x, including reduced motion and model reset.
- Guest session hook: VMware, VirtualBox, KVM and native branches exercised in isolation.
- Existing VMware guest: user confirmed clipboard sharing, automatic mouse release and icon motion.

ISO tests initially reached all checks but the harness failed to recognize a
serial CRCRLF line ending. The parser was fixed and both full tests passed on
rerun. An initial overlay packaging attempt excluded lower files; its output
was rejected and rebuilt before testing. Neither intermediate was published.

VirtualBox end-to-end behavior, audio playback, drag/drop, resizing and the
previously reported arrow-key behavior are not certified by these checks.
The new images were boot-tested in QEMU, not through native VMware UI automation.

## Downloads and source

The [development release](https://github.com/Shadowman8080/Aether/releases/tag/0.3.1-dev.20261006)
provides the ISO, compressed clean VMDK/VMX bundle, source snapshot and checksums.
Build integration is in [build/release-20261006](../build/release-20261006/README.md).
The unchanged pinned upstream source archives remain in the
[0.3.0 assets](https://github.com/Shadowman8080/Aether/releases/tag/0.3.0).

Default development login is `aether` / `aether2026`. Choose a personal password
when installing. The VMX requires a VMware release supporting hardware version
22; firmware is UEFI without Secure Boot. Host auto-grab/ungrab and gaming-mouse
preferences remain host settings, documented in the VM archive.

These assets are manual development downloads. SHA-256 checksums are integrity
records, not signatures; this release does not publish a new signed update feed.
