# Aether 0.3.2 development snapshot — 2026-11-16

This is a refreshed development download, not a production release. It republishes
the 2026-11-12 x86_64 desktop image under a new release tag so the verified ISO,
checksums and VM bundle have a stable download location.

## What was checked

- The ISO's signed live unified kernel image passes `sbverify` against the
  development `db.crt`.
- The ISO boots through BIOS and reaches the Aether welcome dialog. The capture
  used for this record is [bios-live-desktop.png](verification/20261116/bios-live-desktop.png).
- The installer backend completed a fresh UEFI install with the signed shim,
  GRUB and installed UKI present and signature-verified. It reported
  `INSTALLER_UEFI_PASS` and `INSTALLER_BACKEND_PASS`.
- The clean VM disk was converted to a writable monolithicSparse VMDK.
  `qemu-img check` found no errors and `qemu-img compare` reported
  **Images are identical** against the detached raw disk. The VMDK reaches the
  installed GRUB menu under BIOS; the exact menu is shown in
  [vm-bios-grub.png](verification/20261116/vm-bios-grub.png).

## Not verified / still blocked

- **UEFI graphical output is not confirmed for this snapshot.** QEMU/OVMF boots
  the signed image to the login prompt, but independent framebuffer captures were
  black. The supplied VM therefore uses BIOS. Do not treat UEFI desktop operation
  as tested for this download.
- **Physical hardware is not tested.** Secure Boot enrollment, encrypted-root
  unlock, suspend/resume, docking and device behavior have only been exercised in
  virtual machines or fixtures.
- **Public OS updates are not configured.** There is no deployed authenticated
  update repository, operator-owned production trust, rotation/revocation process
  or separate publisher credentials. The update checker is present; it is not a
  working public update feed.
- **The installer is whole-disk only.** `/boot` and the EFI system partition are
  not encrypted; encrypting `/boot` needs a boot-chain redesign.
- AppArmor coverage, a maintained browser, TPM2/FIDO2 unlock, independent backup
  credentials and accessibility validation remain outstanding.

## Downloads and credentials

The ISO and VM bundle are published under the `0.3.2-dev.20261116` tag. Compare
assets with `SHA256SUMS`; these hashes detect corruption and are not release
signatures.

Development login: `aether` / `aether2026`. Change it before storing personal
data. The VM is a 20 GiB BIOS-configured VMware/VirtualBox disk with Secure Boot
not enabled. See the release's `README-VM.txt` for host settings and limits.

The previous 0.3.2 development release and its records remain available. This
snapshot does not claim completion of the next-release acceptance criteria.
